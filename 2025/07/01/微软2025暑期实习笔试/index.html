微软2025暑期实习codetasks

发表于 2025-07-01 分类于 技术分享

以下为微软面向 2025 年暑期实习生的笔试邀请函，现将任务要求和提交指南整理如下，供大家学习参考。请不要将本内容用于商业或其它用途。

题目以及答案链接：https://github.com/CwbyWifsy/microsoft_codetasks_2025

也可以进我个人主页查看：https://cwbywifsy.com/

任务要求（Task Requirements）

  1. 对自己的项目做一个介绍.
  2. 从以下两大部分中选择并完成至少一项：
    • PART I:
      1. Coding Task - Agent (Mandatory)
        • 简要描述：在此任务中，定制一个 Agent，自动化执行以下流程：接受仓库 README，生成 Dockerfile；构建并运行名为 my-vue 的镜像与容器（映射 9528 端口）；在容器内运行测试命令 npx jest tests/unit/utils/validate.spec.js。
      2. Coding Task - Data & Algorithms (Optional Bonus Task)
        • 简要描述：这是一个二元分类任务，可自由设计模型和特征工程。Agent 需读取训练数据（train.csv）与测试数据（test.csv），输出模型的 AUC 分数，并提供简要模型及特征工程说明。
        • 评价指标：AUC（ROC 曲线下面积）。
        • 数据说明：
          • train.csv：用于训练模型
          • test.csv：用于评估模型性能
        • 提交内容：
          • 测试集上的 AUC 得分
          • 模型设计与特征工程的简要说明
          • 完整代码
    • PART II:
      1. Coding Task - Frontend & Backend
        • 说明: 根据自身技术栈与岗位需求，可选择完成以下一至两个子任务：
          • 前端开发（Frontend Development）
            • 在 CodePen 提供的代码骨架中，使用 React.js 或 Vue.js 完成拖拽和列表重排功能（尽量不依赖第三方库）。
            • 提交内容：更新后的 CodePen 链接，以及设计思路与心得文档。
          • 后端开发（Backend Task）
            • 构建一个面向 HTTP 服务的 API 服务器（端口 9527 和 7259）。
            • 使用面向对象设计，支持 CSV 文件的查询与修改操作（INSERT、DELETE、UPDATE），并在设计文档中说明具体实现细节。
            • 提交内容：包含 Dockerfile 或可执行文件的项目压缩包，以及设计思路与心得文档。
        • 输出格式：需严格参照附录 III 示例（Appendix III）。
